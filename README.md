# Модуль Orders Export для OkayCMS

Модуль дозволяє експортувати замовлення з інтернет-магазину у форматі CSV з детальною інформацією про кожен товар у замовленні.

## Можливості

- Експорт замовлень у форматі CSV з кодуванням Windows-1251
- Фільтрація замовлень за статусом
- Фільтрація замовлень за датою (з/до)
- Фільтрація замовлень за мітками
- Експорт номерів ТТН (якщо встановлено модуль [NovaPoshtaTracking](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS)):
  - Додавання колонки з ТТН до експорту
  - Фільтрація тільки замовлень з ТТН
- Детальна інформація про кожен товар у замовленні:
  - Номер замовлення
  - Позначка про кілька позицій у замовленні
  - Статус замовлення
  - Бренд товару
  - SKU товару
  - Назва товару (з варіантом, якщо є)
  - Кількість
  - Ціна
  - Дата замовлення
  - ТТН доставки (опціонально)
- Багатосторінковий експорт (по 100 замовлень за раз) для великих обсягів даних
- Автоматичне завантаження файлу після завершення експорту
- Відображення прогресу експорту в реальному часі

## Вимоги

- OkayCMS v4.5.2
- (Опціонально) Модуль [NovaPoshtaTracking](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS) для експорту ТТН

## Встановлення

### Варіант 1: Скачування з GitHub

1. Скачайте останню версію модуля з [останнього релізу на GitHub](https://github.com/devSviat/OrdersExport-OkayCMS/releases/latest).  
2. Розпакуйте архів на сервері в каталог: `{OkayCMS_root}/Okay/Modules/`

### Варіант 2: Встановлення через Git

1. Виконайте команду в директорії `{OkayCMS_root}/Okay/Modules/Sviat`:
   ```bash
   git clone https://github.com/devSviat/OrdersExport-OkayCMS.git OrdersExport
   ```
### Результат встановлення

Шлях до модуля має бути таким:
   ```bash
   {OkayCMS_root}/Okay/Modules/Sviat/OrdersExport/
   ```

Після встановлення перейдіть в адмін-панель → Модулі → Знайдіть "Export orders" → Натисніть "Встановити"

## Використання

1. Після встановлення модуля перейдіть в адмін-панель → Замовлення → Експорт
2. Оберіть параметри експорту:
   - **Статус замовлення** - виберіть конкретний статус або залиште "Всі статуси"
   - **Експортувати ТТН** (якщо встановлено модуль [NovaPoshtaTracking](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS)):
     - "Не додавати" - ТТН не будуть включені в експорт
     - "Додати ТТН" - ТТН будуть додані як окрема колонка
     - "Тільки з ТТН" - експортуються тільки замовлення, які мають ТТН
3. Натисніть кнопку "Експортувати"
4. Спостерігайте за прогресом експорту на індикаторі прогресу
5. Після завершення експорту файл `export_orders_enhanced.csv` автоматично завантажиться

## Формат експортованого файлу

CSV файл містить наступні колонки:

- **Номер замовлення** - унікальний ID замовлення
- **Позицій** - номер замовлення, якщо в ньому більше одного товару (для зручності фільтрації)
- **Статус** - назва статусу замовлення
- **ТТН доставки** (опціонально) - номер ТТН, якщо обрано експорт ТТН
- **Бренд** - назва бренду товару
- **SKU товару** - артикул товару
- **Назва товару** - назва товару з варіантом у дужках (якщо є)
- **Кількість** - кількість товару в замовленні
- **Ціна** - ціна товару
- **Дата замовлення** - дата створення замовлення

**Важливо:** Кожен товар з замовлення виводиться окремим рядком. Якщо в замовленні кілька товарів, номер замовлення та інформація про замовлення будуть повторюватися для кожного товару.

## Інтеграція з NovaPoshtaTracking

Якщо встановлено модуль [NovaPoshtaTracking](https://github.com/devSviat/NovaPoshtaTracking-OkayCMS), модуль OrdersExport автоматично:
- Визначає наявність модуля та додає опції експорту ТТН
- Додає колонку "ТТН доставки" до експорту
- Дозволяє фільтрувати замовлення з ТТН

## Важливо

- Файл експорту зберігається в директорії `backend/files/export/export_orders_enhanced.csv`
- При кожному новому експорті старий файл перезаписується
- Експорт виконується порціями по 100 замовлень для оптимізації продуктивності
- Файл експортується в кодуванні Windows-1251 для коректного відображення в Excel
- Для експорту великої кількості замовлень може знадобитися час - не закривайте сторінку до завершення процесу
